# Homebrew Tap

Homebrew packages maintained by `mindsurf0176-ui`.

## RelayCode

```bash
brew install mindsurf0176-ui/tap/relaycode
relaycode setup --workspace ~/Projects
```

RelayCode keeps the bridge on loopback and configures private Tailscale HTTPS
access during setup. See the
[RelayCode repository](https://github.com/mindsurf0176-ui/relaycode) for
requirements, security boundaries, and mobile instructions.
